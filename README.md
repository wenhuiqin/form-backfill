# 📡 API 请求监控器 - Chrome 扩展

一个强大的 Chrome 浏览器扩展，用于实时监控和查看网页的 API 请求，支持 URL 过滤配置。

## ✨ 功能特点

- 🎯 **智能捕获**：自动拦截 `fetch` 和 `XMLHttpRequest` 请求
- 🔍 **URL 过滤**：支持配置 URL 规则，只捕获你关心的请求
- 📌 **钉住面板**：可以将重要的请求钉住到屏幕上查看
- 🎨 **美观 UI**：现代化界面设计，支持拖拽和展开/收起
- 📋 **一键复制**：快速复制请求详情到剪贴板
- 🔄 **实时更新**：请求实时显示，无需刷新
- 🎛️ **灵活配置**：支持开关控制，关闭即停止监控

## 📦 安装步骤

### 1. 生成图标文件（首次安装需要）

1. 在浏览器中打开 `icons/generate_icon.html`
2. 点击"📥 下载所有图标"按钮
3. 将下载的 `icon16.png`、`icon48.png`、`icon128.png` 移动到 `icons` 文件夹

### 2. 加载扩展到 Chrome

1. 打开 Chrome 浏览器
2. 在地址栏输入：`chrome://extensions/`
3. 右上角打开"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目的文件夹（包含 `manifest.json` 的文件夹）
6. 扩展加载成功！

## 🎯 使用方法

### 基本使用

1. **启用监控**
   - 点击浏览器工具栏的扩展图标 📡
   - 确保"启用监控"开关是打开状态
   - 访问任意网页，API 查看器会自动显示在页面右上角

2. **查看请求**
   - 所有捕获的请求会实时显示在面板中
   - 显示请求方法、状态码、耗时、URL 等信息
   - 点击"查看响应"可展开查看详细响应内容

3. **搜索过滤**
   - 在搜索框输入关键词，快速筛选请求
   - 支持搜索 URL、方法、状态码等

### 高级功能

#### 📌 钉住请求

点击请求右侧的"📌 钉住"按钮，可以将重要的请求固定在屏幕上：
- 钉住的面板可以独立拖拽
- 支持同时钉住多个请求
- 方便对比不同请求的响应

#### 📋 复制请求

点击"📋 复制"按钮，一键复制请求的完整信息（JSON 格式）。

#### 🎯 URL 过滤配置

1. 点击扩展图标打开配置面板
2. 在"URL 过滤规则"文本框中输入规则
3. 点击"保存配置"
4. 刷新页面生效

**过滤规则示例：**

```
# 捕获所有请求（留空或不填）
（空白）

# 捕获特定域名的所有请求
https://api.example.com/*

# 捕获多个 URL（逗号分隔）
https://api.example.com/*,https://example.com/api/*

# 捕获特定路径（支持通配符）
*/api/user/*,*/api/product/*

# 精确匹配
https://example.com/api/v1/data
```

**通配符说明：**
- `*` 匹配任意字符
- 示例：`*/api/*` 会匹配所有包含 `/api/` 的 URL

### 关闭监控

1. 点击扩展图标
2. 关闭"启用监控"开关
3. 保存配置
4. UI 面板会自动隐藏，不再捕获请求

## 🔧 技术栈

- **Manifest V3**：使用最新的 Chrome 扩展规范
- **原生 JavaScript**：无依赖，轻量高效
- **Chrome Storage API**：配置持久化存储
- **Chrome Messaging API**：扩展内部通信

## ⚙️ 配置说明

### 存储的配置项

- `enabled`：是否启用监控（布尔值）
- `urlFilter`：URL 过滤规则（字符串，逗号分隔）

### 配置存储位置

使用 Chrome 的 `storage.sync` API，配置会同步到你的 Chrome 账号。

## 🐛 常见问题

### Q: 为什么看不到 API 请求？
**A:** 请检查：
1. 扩展是否启用
2. "启用监控"开关是否打开
3. URL 过滤规则是否正确
4. 刷新页面后再试

### Q: 为什么有些页面无法使用？
**A:** 某些特殊页面（如 Chrome 内部页面 `chrome://`）无法注入扩展脚本，这是浏览器安全限制。

### Q: 如何只监控特定接口？
**A:** 在扩展配置中设置 URL 过滤规则，例如：`*/api/*` 只监控包含 `/api/` 的请求。

### Q: 如何清空历史请求？
**A:** 点击面板上的"清空"按钮即可。

### Q: 图标文件在哪里？
**A:** 打开 `icons/generate_icon.html` 生成图标，或者使用任意 PNG 图片重命名为 `icon16.png`、`icon48.png`、`icon128.png`。
